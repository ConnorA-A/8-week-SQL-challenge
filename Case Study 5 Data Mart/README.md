# Case Study 5. Data Mart

[← Back to main README](../README.md)

Data Mart is a grocery retailer that switched to sustainable packaging in June 2020. This case study starts with cleansing a messy weekly sales table, then uses the cleaned data to explore sales trends and measure whether the packaging change affected revenue.

**Tables involved:** `weekly_sales`, `clean_weekly_sales`
