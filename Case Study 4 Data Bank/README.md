# Case Study 4. Data Bank

[← Back to main README](../README.md)

A digital bank wants to understand how customers are distributed across its regional nodes, how often they get reallocated and how their transaction activity behaves over time. This case study works through node exploration, transaction patterns and running/monthly balances.
